## Définition du DevOps
DevOps est une culture, un ensemble de pratiques et d'outils qui permettent de :
## Développer des applications plus rapidement.
## Tester automatiquement le code.
## Déployer les applications de façon continue.
## Surveiller et maintenir les systèmes en production.
